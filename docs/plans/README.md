## 维护规则

- 新待办先写当前台账；仅在内容确实独立时增加专项计划，并从台账引用。
- 专项计划完成或被替代后归档；未结项转回台账，保留来源和关闭条件。
- 功能现状写对应功能文档，操作步骤写指南，实际验证写测试状态，不在计划间重复。
- 旧计划中的命令和完成标记不新增授权；当前会话已明确授权的步骤按原范围继续，环境与代码状态需核准。
- 文档新增、移动和归档遵循[文档规范](../DOCUMENTATION_RULES.md)，同步导航及真实引用。

#### R1 CI 隔离验收方案

**本地实现复核**：Moby 28 的发布端口需要网关有非 `internal` 的出口端点；只给网关加独立回环入口网，应用与数据服务留在内部网络。启动前按实际资源名拒绝占用、按本次归属清理；给中断后独立清理留时间，登录拒绝与 DAP 必须逐项取证。这些是 R1 的本地阻断修正，不代表远端运行已验。

**取证复核边界**：报告逐项对照原工件，job 已取消或最终非 `success` 时不能验收；补回收后记录实际残留，不抹掉首次失败；原生日志只输出固定阶段与安全错误信息，不写含任务标识的请求路径。完成本地正反例前不进入发布。

**入口**：手动触发的 `.github/workflows/release-image-smoke.yml` 只验收已发布的 2.2.11，不改发布流程或六张镜像，也不重跑会推镜像的 `dockerhub-amd64`。该入口已提交并推至独立 PR，尚无 R1 运行记录。现有 [PythonLab PR runtime](../../.github/workflows/pythonlab-pr-runtime.yml) 从源码构建沙箱；将它固定到兼容 runner 只修 PR 检查，不代替 R1。

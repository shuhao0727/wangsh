### 提交 2：`fix(security): 评分智能体支持受信内部端点白名单`

**问题**：`_is_disallowed_ip` 的 `is_private` 拒绝 `172.18.0.2`，评分请求在发出前被拦（503）。

**服务器实测证据**：
- 内网 `docker-api-1:5001` 从 `wangsh-backend` 访问 **0.0s 响应**（网络完全通）
- 公网 `wangsh.cn:6606` 从容器访问 **6.8s 超时**
- ID22 是 `advanced-chat`，**支持 blocking**

**改动**：
- `backend/app/core/config/_services.py`：新增 `AGENT_TRUSTED_INTERNAL_ENDPOINTS`
- `backend/app/services/agents/endpoint_security.py`：新增四元组匹配 + 短路分支
- `backend/app/services/ai_partner_evaluation.py:200`：传 `allow_trusted_internal=True`
- `.env.example`：加空值默认
- 测试：`backend/tests/ai_agents/test_model_discovery_ssrf.py` 扩充

**四元组规则**（缺一不算）：scheme 全等 + host 完全相等 + port 显式 + path 前缀在 `/` 边界

**关键**：`_is_disallowed_ip` **一行不改**，命中白名单是短路，未命中继续全拒。

**验证**：
- L1 单元：8 个用例（命中放行、异 port 拒、path 越界拒、近似 host 拒、未命中内网拒、`169.254.169.254` 拒、非法条目启动失败）
- L2 集成：MockTransport 验证不再 503、payload 不含 `conversation_id`
- L3 服务器：`POST /api/v1/ai-partner/evaluate` 期望 200

### 提交 3：`fix(dify): 流式对话携带历史上下文（有界重放）`

**问题**：`build_stream_payload` 只取最后一条 user 消息，历史全丢。

**服务器证据**：Dify 有 55 个会话，每条提问都新建独立会话。

**改动**：`backend/app/services/agents/providers/dify_provider.py:35-47`

- 历史拼进 `query`，但**有明确上限**：最近 4 轮（8 条）、总长 3000 字符
- 超出则截断更早轮次
- 格式：`[历史对话]\n用户: ...\n助手: ...\n[当前问题]\n用户: ...`

**为什么不是终态**：Dify 侧会话列表/统计会碎（每条算新会话）。终态见下一版。

**验证**：
- 单元：`query` 长度不超限、历史顺序正确、单轮时不加前缀
- L3 服务器：同一会话追问「刚才的编号」能正确回答

### 提交 4：`fix(users): 唯一性检查限制单行，避免双字段冲突 500`

**问题**：`users.py:249`（create）和 `:321`（update）的 `scalar_one_or_none()` 缺 `.limit(1)`。

**实测**：造 A(username=a, student_id=y)、B(student_id=x)，`POST /api/v1/users` 传 `{username:a, student_id:x}` → **500** `Multiple rows were found`

**改动**：两处加 `.order_by(User.id).limit(1)`

**验证**：
- 双字段冲突 → **400**（不是 500）
- 单字段冲突仍正常 400
- PUT 路径同样

### 提交 5：`fix(xbk): 导入畸形文件返回 400 而非 500`

**问题**：
- 非法 UTF-8 CSV → **500** `'utf-8' codec can't decode`
- 破坏的 xlsx → **500** `File is not a zip file`
- **非法角色值静默降级成 `student`**（`import_service.py:190-191`）

**改动**：
- `import_service.py:50`：`content.decode("utf-8-sig")` 包 `UnicodeDecodeError` → 400
- `import_service.py:64`：`load_workbook` 包 openpyxl 异常 → 400
- `import_service.py:190-191`：非法角色改为行级 error

**验证**：
- 非法 UTF-8 → 400
- 破坏 xlsx → 400
- 非法角色 → 行级 error（不是静默降级）

### 提交 6：`fix(ui): 修复移动端文章目录高度为 0`

**问题**：`SplitPanePage.tsx:24` 的 `gridTemplateRows: "minmax(0,1fr)"` 只有一行，但塞了两个子元素。`isStacked` 时目录面板高度被压成 0。

**实测**：375px 下 `gridTemplateRows` 计算为 `"0px 662px"`，`.article-left-pane` 高度 0、`overflow:hidden`，**目录完全不可见**（`tocItemCount=7` 但渲染高度 0）。

**改动**：`SplitPanePage.tsx` 在 `isStacked` 时改为 `gridTemplateRows: "auto minmax(0, 1fr)"`，并给左侧加 `max-height` + 内部滚动

**验证**：375px 视口下目录可见且可滚动

## 归档规则

- 已完成的一次性计划、阶段分析和事故复盘可归档。
- 归档前必须把当前行为沉淀到 owner 文档。
- 没有唯一历史价值、没有引用且已有完整替代的临时记录可以直接删除。
- 只有真实引用或迁移窗口依赖旧路径时才保留短 redirect。

详细生命周期规则见
[DOCUMENTATION_RULES.md](../DOCUMENTATION_RULES.md)。

## 镜像到服务器的传输

- 服务器访问不了 Docker Hub（registry ping 超时），本次不再使用 2.2.8 的临时代理中继。
- 操作机用 `skopeo inspect --raw` 核对六个 ref 的 manifest digest 与 release-set 一致、含 linux/amd64；再用
  `skopeo copy --all --preserve-digests` 按 digest 生成 OCI 归档（共约 755MB），本地核对每个归档 `index.json`
  根 manifest 等于 release-set digest。
- scp 后服务器逐文件 SHA256 一致；`import_exact_oci.py` 逐个校验归档 SHA、根 digest 与每个 blob 后 `docker load`，
  六个镜像 `Id` 均等于 release-set digest，RepoDigest 与平台通过。
